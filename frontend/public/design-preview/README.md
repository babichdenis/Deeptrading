# Макет 03 — полный фронтенд с компактной панелью

Исправляет ограничение первого эскиза: основу теперь составляет **полная рабочая разметка**, а не упрощённый обзор. Сохранены Бот/Склад/Анализ, шесть показателей, быстрые торговые настройки, обе боковые панели, все исходные формы, столбцы таблиц и вкладки отчётов.

## Открыть

- Локально: `http://127.0.0.1:8766/design-preview/?v=3` — пока работает отдельный static preview.
- На существующем Vite: `/design-preview/index.html`.
- Можно открыть `index.html` напрямую: внешних запросов и зависимостей нет.
- Прежний ограниченный эскиз: `overview-v1.html`.

## Карта функций

[Полный разбор исходников и план переноса](../../../docs/knowledge/FRONTEND.md).

В HTML сохранены **249 исходных id и 159 нативных элементов управления**. Это проверка сохранения разметки, не приёмка визуального поведения или backend-функций. Динамические области заполнены самостоятельными demo fixtures: полный серверный реестр/текущие позиции/результаты не загружались.

## Файлы

- `index.html` — производная полного рабочего frontend/index.html.
- `workbench-base.css` — снимок исходного CSS, чтобы оценивать существующую геометрию.
- `workbench.css` — отдельная тема и правила размещения, основные данные 13–14px.
- `workbench.js` — синтетические данные и локальные действия; API-клиенты приложения не подключены.
- `source-map.json` — входные файлы, hashes, исходные controls/ID и вкладки.
- `layout-preservation.json` — результат сопоставления разметки.
- `overview-v1.html`, `theme.css`, `preview.js` — сохранённый первый эскиз.

Визуальное направление вдохновлено [Solid Glass](https://github.com/deeplethe/solid-glass); React/shadcn/Tailwind не устанавливались.

## Что можно оценить

Три колонки рабочего экрана, изменение ширины и сворачивание панелей, высота графика, переходы по основным разделам, рынок/AI, выбор бумаги→график, раскрытие сделки, полные формы настроек и теста, поиск/сортировка примеров рынка, фильтры логов, таблицы/карточки тестов, все вкладки отчётов. Широкая таблица сохраняет поля через горизонтальную прокрутку; кнопка разворота временно отдаёт ей полную ширину.

Политика примеров: кнопка настоящего торгового действия показывает уведомление или меняет исключительно локальное представление. Сохранение промпта, AI-сообщение, расчёт сигналов, запуск теста, смена режима и закрытие позиции не обращаются к серверу. Часть сложных backend-действий представлена только местом и подписью — production-паритет этим макетом не заявлен. Автоматический запуск по таймеру конфликта preset/UI в макете отключён и подписан.

## Следующий этап

Сначала согласовать вместимость **полного** экрана на рабочих сценариях. Затем по одному переносить тему/компоненты с сохранением DOM-id, обработчиков, состояния и контрактов данных. Исходный рабочий frontend, backend, зависимости и торговые настройки этим этапом не менялись. Выполнена проверка JS-синтаксиса; сборка и test suites не запускались. Браузерная визуальная проверка не выполнена: предыдущий доступ browser tool был отклонён политикой.

## Компактная панель — версия 03

Над графиком вместо раскрытого набора настроек находятся шесть нативных details-групп со сводками: сессии/сверка, направления, маржа, режимы, капитал, контур/AI. Исходные поля и их id сохранены; режим счёта и AI-select перемещаются в группу после инициализации. Пауза/старт/статусы остаются видимыми. Одна группа открывается поверх рабочего поля и закрывается по Escape/внешнему нажатию. На узком desktop группы занимают два ряда. `quick-controls.js` отвечает за сводки и размещение; production-файлы не менялись. Высота в реальном браузере не измерялась.
