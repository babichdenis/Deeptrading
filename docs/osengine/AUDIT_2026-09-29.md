## C. Механика входов/выходов: порт vs оригинал

**Совпадает:** два слота стоп/тейк на позиции; OCO (при срабатывании одного второй снимается);
приоритет стопа при касании обоих в одном баре (консервативно); TryReload no-op при тех же ценах;
порядок «close → open» в CandleFinishedEvent.

**Упрощено / иначе (влияет на бэктест):**
1. Лимитные заявки исполняются мгновенно (в C# — через ордерный эмулятор тестера) → сделки «идеальнее».
2. **Нет ratchet у трейлинга**: оригинал стоп назад не двигает, порт перезаписывает слот любым уровнем.
3. Цена исполнения: в тестере OsEngine `TryReloadStop` принудительно `priceOrder = priceActivate`;
   порт использует переданный `order_price` → при slippage системный сдвиг цен сделок.
4. Активация по `low/high` свечи (в оригинале — по тикам/стакану; внутрибаровый порядок касаний невосстановим).
5. Гэп исполняется по `order_price`, а не по `open` (в основном движке Deeptrading `exits.py` — по open).

**Отсутствует:** вход `buy_at_market/sell_at_market`; market/limit-варианты стоп-входа
(stop-market, stop-iceberg, StopToPosition); `CloseAtStopCancel` (снятие слота без закрытия);
per-side отмена входных стопов; expiry входных заявок (OpenerToStop.ExpiresBars);
частичные закрытия и перевыставление слотов на остаток; теги причины выхода в fills.
