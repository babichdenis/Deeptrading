# Фронтенд: карта функций и план переработки

Срез **2026-10-16**. Основание — полный `frontend/index.html`, структура `main.ts`, чтение обработчиков, динамических шаблонов, API-клиента и модуля отчётов. Это разбор исходников; внешний вид рабочего приложения с живыми данными в браузере этой сессией не осмотрен. Данные со счёта, БД и внешних API не запрашивались.

## Действующая точка входа

`frontend/index.html` → `src/main.ts` → `api.ts`, `analytics/reports.ts`, shared DOM/HTTP, lightweight-charts. В `main.ts` две ветки: обычное приложение и `?embedded=1` для графика. Три основных раздела: **Бот, Склад, Анализ**. Название «Склад» соответствует `data-page=chart`, а не отдельному маршруту графика.

`lab.ts`, `enslab.ts`, `test.ts`, `labchart.ts`, `ws.ts` содержат отдельные функции/экраны, но текущий `main.ts` их не импортирует. Они учтены как отдельные модули; наличие файла не доказывает достижимость из текущей навигации. Не добавлять их автоматически в действующий UI под видом уже доступных экранов.

Исходная статическая разметка содержит **249 id и 159 нативных элементов управления**: кнопки, поля, select и textarea. Динамически создаваемые элементы идут сверх этого числа.

### Все поля открытых позиций

Вход-время; акция; side; qty; вход; сумма/свои; текущая цена; P&L ₽; ROI%; плечо; режим входа/текущий; vol; SL/trail; TP/информация о стопе в заголовке; действие. Не заменять эту таблицу карточкой с семью полями и не смешивать notional, собственные средства и margin.

### Все поля последних сделок

Время входа→выхода; акция; направление с RSI/режимом; qty; сумма/свои; плечо; цена входа→выхода; доход; комиссия; причина выхода; вход/голоса/режим; R; раскрытие. Раскрытие — отдельный пользовательский сценарий, а не необязательный декор.

### Поля списка тестов

Выбор; имя; период; trades; wins; losses; gross win; gross loss; net; PF; WR%; открытые; действия. Повтор создаёт новый прогон, а не перезаписывает старый. Переход к аналитике должен сохранять выбранный test_name.

## Склад

График и OHLC-легенда; интервалы 1/5/15м, час, день; SMA/EMA/Bollinger/RSI/MACD, отдельные indicator panes, log scale и sync. Внизу — каталог стратегий с правилами, enable, параметрами и ролями BIAS/SETUP/ENTRY; конструктор и политика выхода; выбранные сигналы/маркеры; входные гейты; схема bias→setups→quorum→order и диагностическая воронка.

Источник: `index.html:200–260`, `main.ts:4381–4958`. В рабочем режиме включение функции/гейта может менять runtime, а не только фильтр отображения. При переносе не менять эту семантику незаметно.

Период и источник, размер слота/экспозиция, сравнение выбранных тестов, AI-экономика/контрфакт, AI-отчёт с моделью/временем/usage/предложениями, heatmap 30м с bias/режимом, движения 1д/1н/1м/3м, портфель с экспозицией/маржой/стрессом/очередью/rank/DD/секторами/пропусками, общие показатели и **9 срезов**: side, bias, regime, session, ticker, entry reason, exit reason, strategy votes, quorum.

### Прогоны

Источник harness/replay, вид real/wf/matrix/exp, поиск, список прогонов, период/теги/конфигурация, повтор/удаление. Четыре панели: **Роботы / Срезы / Сделки / Рынок**. Есть восемь измерений срезов, фильтры сделок outcome/ticker/side/exit/entry, итог, пагинация, показатели SL/TP/MAE/MFE/bars, рыночное окно день/неделя/месяц.

Источник: `index.html:397–450`, `src/analytics/reports.ts:226–861`. Поля/метрики зависят от источника; отсутствие не подменять нулём. Переход из теста в отчёт и фокус сделки на графике — контракты состояния.

## Формы и опасные границы реального UI

- Настройки бота: ATR/fixed, optuna/manual, override SL/RR, период/mult/RR ATR, fixed SL/TP, topN, комиссия, re-entry cooldown, confirm flip, quorum. Часть применяется сразу, часть при старте.
- Новый тест: пресет и custom override, сессии/overnight/EOD, капитал/position%/qty/max positions/exposure, exits/trail, входные гейты и их keep/custom, cooldown/flip/last hour/vol, режимы, имя, engine, TF, from/to, persist logs. Сохранение формы и границы пользовательской timezone→UTC.
- Конфликт preset/UI: явный выбор источника параметров; текущий production содержит таймер и fallback. Стилистическое изменение не даёт права менять это поведение. В макете 02 автоматический запуск намеренно отсутствует, что явно подписано.
- Live/Sandbox/Test может перезапускать реальный бот; закрытие позиции отправляет заявку; AI промпты/сообщение и гейты изменяют серверное состояние. В макете 02 ни один API-клиент не запускается.

## Исправленный макет 02

Адрес: `/design-preview/` либо `/design-preview/index.html`. Построен из полной рабочей HTML-разметки, тема берётся из сохранённого снимка текущего CSS с отдельным оформлением Solid Glass. **Все 249 исходных id и 159 исходных статических controls сохранены в разметке**. Динамические контейнеры заполнены независимыми демонстрационными fixtures; это не обещание реализации production-логики или полного реестра стратегий.

Файлы: `frontend/public/design-preview/index.html`, `workbench-base.css`, `workbench.css`, `workbench.js`, `source-map.json`. Прежний упрощённый обзор сохранён как `overview-v1.html`; его оформление не используется для вместимости терминала.

Геометрия: компактная общая шапка вместо огромных metric cards; те же три рабочие колонки. Основные данные 13–14px, таблицы сохраняют все столбцы через внутренний горизонтальный scroll. Для большой таблицы есть явный временный разворот на полную ширину с возвратом панелей; ничего не убрано автоматически ради красоты. График, боковые панели и AI-блоки меняют размер. Малый экран допускает прокрутку рабочего полотна; полноценная мобильная версия этим этапом не обещана.

## Макет 03 — компактные настройки над графиком

По замечанию владельца раскрытые быстрые настройки заменены шестью группами со сводками текущего состояния: сессии/сверка, Long/Short, маржа/плечо, режимы, слот/число/×EQ, контур/AI. Это перемещение существующих полей, без удаления возможностей. Пауза/старт/стоп и состояние видимы постоянно. Финансовые показатели — компактная строка. Группы открываются поверх, а не отодвигают график вниз; клавиатура, Escape и внешнее нажатие поддержаны. На узком desktop допускаются два ряда. Реальная экономия высоты не измерялась; визуальная приёмка остаётся открытой.
