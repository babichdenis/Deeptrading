## BUY-фильтр D1 (внедрение рекомендации отчёта) — 2026-10-19

По итогам анализа признаков прибыльных BUY-сделок внедрён фильтр BUY-входа по последнему **завершённому** дню MSK: `d_rsi<=45 AND d_atr>=2.4286 AND h_ret3>0`, где `d_rsi`/`d_atr` — SMA-RSI(14)/ATR(14) на дневных свечах предыдущего дня, `h_ret3` — 3-барный доход H1 по закрытым барам. Реализация: модуль `backend/app/bot/entry_filter_d1.py` + env-гейт `ENTRY_FILTER_D1` (`1/true/on/yes`), пороги переопределяемы `ENTRY_FILTER_D1_RSI_MAX` / `ENTRY_FILTER_D1_ATR_MIN`; блок в `_enter_confirm` (`backend/app/bot/runtime.py:6159-6191`). При выключенном флаге поведение не меняется (проверено структурно и прогоном `tg_d1ctl`); при нехватке данных — fail-open; reject → `order.status="CANCELLED"` + событие `ENTRY_FILTER_D1` + `_trace_order_reject`. По умолчанию **выключен** (prod `.env` флаг не задаёт).
