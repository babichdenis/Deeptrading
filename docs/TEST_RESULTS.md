# Результаты тестов ансамбля (rule-based, ML выключен)

Дата: 2026-08-25
Конфигурация: `ensemble_main_v1` (зафиксирована)

## Что тестируем

Пайплайн: **BIAS (1h EMA50) → SETUPS (7 функций на 5m) + кворум → ENTRY (5m микро-брейкаут) → движок (стоп/тейк/выход по сигналу)**

| Параметр | Значение |
|---|---|
| BIAS | 1h EMA(50), режим `info` (не veto) |
| SETUPS | 7 функций каталога на 5m (RSI, Bollinger, Pullback, VWAP, Squeeze, MACD, Donchian) |
| Кворум | 2 из 5 (same-bar) |
| ENTRY | микро-брейкаут на 5m (close > high[1]), исполнение по open следующего 1m |
| Входы | только основная сессия (10:00–18:45 МСК) |
| Перенос ночи | разрешён (`carry_overnight=true`) |
| Cooldown | 15 баров (запрет повторного входа той же стороны) |
| Выход | по сигналу / стоп / тейк (движок EngineRunner) |
| Комиссия | 0.05% за сделку |
| Проскальзывание | 2 bps |
| Размер позиции | 100 000 ₽ на позицию (нормирован капиталом) |
| Универсум | RUAL, AFLT, SNGSP, MVID, NLMK (цена 26–68 ₽) |

**Важно:** результаты ин-семпл на июне (параметры подбирались на июне/августе), июль — независимая валидация (параметры не трогали).

## Что это значит

1. **`entry_session=main` — подтверждённая policy** на двух независимых месяцах (10/10 в пользу main).
2. **Позиции не переносятся через ночь** при текущих правилах (carry = flat) — перенос не влияет на результат.
3. **Устойчивость к издержкам** — стратегия остаётся прибыльной при ×2.0 комиссий/слипа.
4. **Честные оговорки:**
   - июнь/август использовались для выбора параметров (ин-семпл);
   - июль — единственный полностью чистый OOS-месяц;
   - нужен следующий нетронутый месяц (сентябрь) для подтверждения;
   - ML не участвует (rule-based baseline).

## Следующие шаги

1. Август как дополнительный OOS-слой (параметры не менять).
2. Walk-forward по последовательным месяцам.
3. Подключение ML-фильтра — только как отдельный OOS-эксперимент.
