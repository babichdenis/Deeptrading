# Документация Deeptrading

Единый вход: [база знаний](knowledge/README.md). [Каталог всех документов](knowledge/DOCUMENT_INDEX.md) задаёт их роль и актуальность.

Тематические знания находятся в `knowledge/`; завершённые работы — в [PROGRESS](PROGRESS.md), решения — в [adr](adr/README.md), отчёты — в `results/`, исторические стартовые инструкции — в [archive](archive/2026-10-15/README.md).

Полный активный пакет работников [PARALLEL-DAY-1](PARALLEL_DAY_1.md) сохранён по прежнему адресу. Статусы читать в [CURRENT_STATE](knowledge/CURRENT_STATE.md), а не в старых планах.
