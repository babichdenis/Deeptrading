Mixins сохраняют единое состояние runtime: это первый механический этап, не окончательное разделение владения состоянием.

## Дополнительные находки для отдельных исправлений

- `ensemble_diagnostics._counterfactual_reentries` публикует costs с slippage, но net вычитает только комиссии; `_counterfactual_hold` тоже не применяет параметр slippage к net. Это существовавшая ошибка диагностического расчёта. Перенос сохраняет прежнюю арифметику; исправление должно отдельно перейти на общий accounting и явно изменить версию диагностического результата.
- Heatmap endpoint выполняет запросы по каждому FIGI: агрегат часов, предыдущая цена, затем метаданные. Для30 бумаг — до90 запросов. Следующий ускоряющий этап: bulk reads на общий набор FIGI и раздельный расчёт per-ticker; измерить query count и peak memory. В этом этапе SQL heatmap не менялся.
- `trade_history` выгружает всю историю закрытых sandbox сделок; `daily_bias_map` — все доступные дневные строки по выбранным FIGI. Для больших историй нужны SQL aggregates/bounded windows с сохранением последней пятёрки и точного warmup, а не произвольный LIMIT.
- Полные ошибки Ruff в legacy-модулях не равны регрессиям патча. Проверен baseline:4 diagnostics F/E9, после выделения осталось3 старых в ensemble; новые модули проходят F/E9.
