4. Решение — по ЗАКРЫТОМУ ПОЛНОМУ 10min-бару (факт известен к моменту метка+10min); вход — open следующего бара (next_open, runner.py:642–643); внутрибарная неоднозначность SL/TP — пессимистично: SL раньше TP. **ВРЕМЯ-ВЫХОД**: последний обычный выход — сигнал на close ПОЛНОГО бара с меткой 18:20 (окно 18:20–18:30), исполнение open бара с меткой 18:30 (18:30–18:40). Это штатный next_open, НЕ «прямой time-exit на заранее известном open» — такая механика допустима только отдельной явной будущей задачей и сейчас next_open не подменяет. Флаг force_flat НЕ обеспечивает 18:45 и отсутствие overnight сам по себе.
5. Cutoff: последний решающий бар для ВХОДА — метка 18:10 (вход open 18:20 < 18:30); новые входы с вход-open ≥18:30 запрещены. Если необходимого exit-бара нет (нет полного бара с меткой 18:20 или бара с меткой 18:30 с валидным open) → сессия/прогон **INCOMPLETE**: цену не выдумывать, «плоскую позицию» не заявлять. Срабатывание force_flat = нарушение спецификации (тревога/INCOMPLETE), а не плановый выход 18:45.
6. Полные бары и warmup: ПОЛНЫЙ 10min-бар = все 1m-компоненты присутствуют и завершены; правило «первого существующего бара» НЕ используется — день пропускается, вход/решение не сдвигаются к удобной доступной цене. ATR14(10min, Wilder): минимум 14 завершённых TR; ЕДИНАЯ фиксированная инициализация для S1 и S2 (первый ATR = среднее первых 14 TR, далее ATR_t=(13·ATR_{t−1}+TR_t)/14); расчёт каузально строго до решающего бара; невалидный ATR (≤0/не конечный) пропускает день И у S1, И у S2. Сделок в warmup-барах нет; максимум один вход/день; один exit-профиль на эксперимент (ограничение A2).

### 5.1 S1 — внутридневной моментум
Фиксированные параметры (собственный выбор): TF=10min; ATR 14 баров (Wilder, инициализация §4.6); SL=2.0×ATR14, фиксируется на решающем баре; TP нет.
- day_open = open ПОЛНОГО 10min-бара с меткой 10:00 (10:00–10:10); полного бара нет → день пропускается. half_ret(t)=c(t)/day_open−1.
- Решение — строго полный бар с меткой 12:00 (S1-A; закрыт к 12:10) или 14:00 (S1-B; закрыт к 14:10); полного бара нет → день пропускается. |half_ret(t)|>theta → side=sign(half_ret), вход next_open = open бара с меткой 12:10/14:10 (бар отсутствует/нет валидного open → день без входа); иначе день без сделки. ATR14 невалиден на решающем баре → день без сделки.
- Выход: SL (внутрибар, пессимистично) или время — сигнал на close ПОЛНОГО бара с меткой 18:20, исполнение open бара с меткой 18:30 (§4.4–4.5); exit-баров нет → INCOMPLETE. Один вход/день, ре-входа нет.
- **S1-A**: метка решения 12:00 (Delta=120 мин), theta=0.4%.
- **S1-B**: метка решения 14:00 (Delta=240 мин), theta=0.3%.

Итого вариантов S1: **2**. Обоснование фиксаций: Delta 2ч/4ч ≈ ⅓–⅔ day-сессии; theta 0.3–0.4% — порядок дневного размаха ликва MOEX (собственная калибровка, уточняется DQ); ATR 14 / SL 2×ATR — конвенция, одна на оба носителя.

### 5.2 S2 — гэп-фейд
- prev_day_close = close ПОЛНОГО 10min-бара предыдущей main-сессии (10:00–18:45) с меткой 18:30 (18:30–18:40 — последний ПОЛНЫЙ бар при глобальных 10min-бакетах; НЕ 18:40–18:50 с данными за границей сессии). «Предыдущая торговая дата» = ближайшая предыдущая дата с барами main-сессии в пределах5 календарных дней. Если на ЭТОЙ дате отсутствует полный бар18:30 — день пропускается; подставлять close более старой даты нельзя. Соответствие календарю торгов требует проверки перед экспериментом. day_open — как в §5.1. gap=day_open/prev_day_close−1.
- Решение: при |gap|≥g_min — строго полный бар с меткой 10:20 (S2-A; закрыт к 10:30) или 10:30 (S2-B; закрыт к 10:40); полного бара нет → день пропускается. cont(t)=c(t)/day_open−1 (знаковая формула, одна для обеих сторон); сигнал фейда: sign(cont)≠sign(gap) ИЛИ |cont|<0.25·|gap|; side=−sign(gap); вход next_open = open бара с меткой 10:30 (S2-A; доступность 10:30) / 10:40 (S2-B; доступность 10:40); бар отсутствует/нет валидного open → день без входа. ATR14 (единая инициализация §4.6) невалиден → день без сделки; SL=entry−sign·2.0×ATR14 (ATR14≤0/не конечен → день пропускается); TP=entry+sign·3.0×ATR14 (R:R=1.5); внутри бара пессимистично (SL раньше TP). Выход: SL/TP/время (close полного бара 18:20 → open 18:30); exit-баров нет → INCOMPLETE. Один вход/день.
- **S2-A**: g_min=0.7%, метка решения 10:20 (T_conf=20 мин).
- **S2-B**: g_min=1.2%, метка решения 10:30 (T_conf=30 мин).

Итого вариантов S2: **2**. Совокупно бэктест-вариантов носителей: **4** (гейты §9 — отдельные допуски поверх носителя, не носители и не новые стратегии). ### 9.3 Правило допуска (СОБСТВЕННАЯ адаптация; эффект UNVERIFIED)

Фактор F рассчитывается на решающем баре носителя по контрактам §4. Пусть side — сторона сигнала носителя. Порядок проверки ЖЁСТКИЙ (п.4 REWORK): (1) нейтральная зона — |F|≤z → день без сделки, проверяется ПЕРВОЙ (устраняет конфликт r3 при 0<F≤z); (2) знак — sign(F)=side → сделка разрешена, sign(F)=−side → день без сделки; (3) фактор несвежий/отсутствует на дату → день без сделки (никогда не «по умолчанию в сторону»). Знак sign(фактора)=side экономически НЕ задан для любой бумаги a priori: для одной выбранной секторной гипотезы фиксируются носитель (конкретный инструмент), корзина/веса прокси (без текущих победителей задним числом), формула относительной силы, один внешний фактор и экономически мотивированное направление воздействия; нефтяная/золотая гипотезы могут остаться отложенными с честным описанием зависимости. Параметры фиксируются до прогона: A — z∈{0.1%, 0.2%} по |ret| сектора-прокси за предыдущий день; B — z=0 (чистый знак дневного ретёрна валюты). Выход/SL/время — у носителя без изменений (§4, §5).
