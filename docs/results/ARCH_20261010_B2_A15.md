## 2. Контракт данных (`data_contract.json`)

Сущности: **event** (event_id/source/version_id/version_hash, received/published/first_seen/last_seen
в UTC), **analysis** (analysis_id/input_version_id/input_hash/prompt_hash/model/config_version/completed_at/import_kind/validation),
**candidate** (ticker/side/decision_time/price_strategy_version/data_version/external_ref),
**shadow_decision** (branch/decision/reason_code/evidence/decided_at),
**coverage** (mandatory_sources/freshness/unknown), **base_trade** (entry/exit/net/R/status),
**outcome** (veto_effect/avoided_loss/missed_profit). UNKNOWN/error сохраняются явно.

## 3. Эталон пользы

Сравнение — заранее фиксированное сопоставление **одних и тех же базовых сигналов A/B/C**
после издержек (не «нейросеть угадала новость»): одинаковое исполнение/costs, veto
отменяет вход, влияние на капитал/позиции — полный replay каждой ветки, метрики: net
after costs, prevented loss, missed profit, trade_count, unknown_coverage. Результат
измеряется после доступного входа; критерий/порог фиксируются ДО оценочного периода;
современная LLM на старых новостях — исследовательский материал, не holdout.

## 4. Исключение future leakage

`decision_time` — единственное время решения; видны только версии `first_seen_at<=decision_time`
и анализ `completed_at<=decision_time`; исправленный заголовок не виден прежнему snapshot;
revert B→A = новая версия; **отсутствующий исторический first_seen не восстанавливается
выдуманной датой** (unknown остаётся unknown); текст новости — данные, не инструкции;
timeout/ошибка ≠ «новостей нет»; `MODEL_UNAVAILABLE` ≠ успех.

## 5. Минимальные будущие действия

- **Оператор:** дать локальный архив новостей/сохранённые payload; для ветки C на реальных
  данных — рабочий base endpoint (сейчас UNVERIFIED); ручная разметка `labels` на сохранённых версиях.
- **Требует нового разрешения:** периодический сбор (сеть); подключение теневого контура к
  runtime/гейтам; массовые LLM-вызовы/подписки/платные архивы.

## 6. Ручные timeline-примеры (`timeline_examples.json`)

1. **TL1 поздняя новость:** published 05:00Z, received/first_seen 09:00Z, решение 06:00Z →
   событие НЕ видно; B=no_risk_keyword, C=insufficient_coverage/unknown; late-arrival зафиксирован, но не задним числом.
2. **TL2 исправленный заголовок:** v1 08:00Z «SBЕR: сбой» → v2 12:00Z «…устранён»;
   snapshot 09:00=v1, 13:00=v2; анализ привязан к input_version_id; revert = новая версия.
3. **TL3 модель недоступна:** endpoint DOWN → C=unknown/MODEL_UNAVAILABLE (не копия B, не успех);
   A/B работают; ошибка сохраняется явно.
