## 3. Текущая конфигурация риска (боевой бот, `.3`)

| Параметр | Значение | Что ограничивает |
|---|---|---|
| `max_net_exposure_pct` | 0.5 | \|LONG−SHORT\| ≤ 50% equity (в bear/bull-режиме → 100%) |
| `max_sector_pct` | 0.35 | сектор ≤ 35% equity (в тренде 40%) |
| `max_margin_use_pct` | 0.8 | starting_margin ≤ 80% equity |
| `max_stress_loss_pct` | 0.10 | убыток при ±5% IMOEX ≤ 10% equity |
| `max_positions` | 5 | одновременных позиций |
| `pos_pct` | 0.4 | слот = 40% equity |
| `top_boost` | 2.0 | топ-1 очереди входит ×2 слота (80% equity) |
| `queue_enabled` | true | очередь кандидатов, отклонённых лимитом |
| `queue_ttl_min` / `queue_interval_sec` | 30 / 120 | TTL кандидата / период проверки |
| `queue_min_turnover` | 300 000 ₽ | floor ликвидности (₽/день) |
| `queue_adv_multiple` | 200 | слот ≤ 1/200 дневного оборота (0.5% ADV) |
| `queue_history_veto` | true | вето токсичной истории |
| `rank_enabled` | true | ранжирование тикеров |
| `rank_top_n` / `rank_explore` / `rank_min_hist` | 10 / 10 / 5 | торгуем топ-10 после 10 разведочных сделок |
| `dd_reduce1_pct` / `dd_reduce2_pct` | 0.05 / 0.10 | просадка от пика → закрыть 50% / 80% позиций |
| `ai_approval` | true | AI-гейт одобряет входы (Big Pickle + llama-советник) |

Все параметры меняются горячо: `PATCH /api/v1/bot/config {"rank_top_n": 5}` и т.п.

## 4. Выводы

1. **Фильтр истории — главный.** 279 отсечённых сделок дали −630.6₽ (PF 0.35, WR 20.4%) — именно они превращали систему в убыточную. Без них: −310.7₽ → +320.0₽ (PF 0.88 → 1.20).
2. **Концентрация в топ-N усиливает результат.** «Не в топ-5» = −779.5₽ (PF 0.49). После разведки топ-5: +468.8₽, PF 1.44, WR 34.1%, комиссии падают с 1109₽ до 591₽.
3. **Разведку убирать нельзя:** первые 10 сделок каждого тикера дали +322.1₽ (PF 2.57) — без неё теряем прибыльные сделки и не получаем статистику для ранжирования.
4. **Ликвидность у нас не проблема:** 0 отсечённых даже при пороге 2.5M ₽/день. Правило оставлено «на будущее» — оно включится само при росте капитала (порог = слот × 200).
5. **Тикеры не «похоронены»:** все 28 торгуются, отсекаются только сделки. Вето затрагивает 5 тикеров с явно токсичной историей (SBER, ALRS, AFLT, VTBR, TATN), и то лишь после 20 сделок.
6. **Практический выбор:** `rank_top_n=5` даёт лучший PF (1.44), `rank_top_n=10` — больше сделок при PF 1.27. Текущий дефолт — 10 (мягче, легче набирает статистику).

## 5. Оговорки

- **Walk-forward** по истории сделок, но сделки совершались **другими настройками** (без этих фильтров) — часть эффекта может объясняться тем, что фильтр отсекает конкретный убыточный период (17.08–15.09), а не «плохие тикеры» вообще. Это честная онлайн-фильтрация, но не гарантия на будущее.
- **Ликвидность** взята текущая (исторической нет). Для отсечения неликвида на будущее это корректно, для ретро-теста — приближение.
- **Топ-N (in-sample)** по суммарному net — с подглядыванием; в таблице он приведён отдельно (вариант «Только топ-N in-sample»), основной результат — **walk-forward** топ-N.
- Комиссии в таблицах — фактические из сделок (`commission`), не пересчитанные.
