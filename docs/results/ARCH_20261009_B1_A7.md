нестрогое `>=` через `a >= b - EPS`, строгое `<` через `a < b - EPS`; равенство
отображается на каноническую семантику (граница = нестрогое/нестрогое правило).

fade `abs(cont) < 0.25*abs(gap)`.

(error — строка отброшена; notice — схлопывание идентичных дублей). **Минута, для
которой найдена хотя бы одна битая строка, исключается целиком (`minute_corrupted`):
валидный дубль не делает минуту «бесспорной»** (п.5). Ничего не чинится молча.

## 6. Почему локальная реализация, а не общий engine

Канон A4 §4.8 прямо называет это точкой будущей реализации («time-conditioned
стратегия в engine сегодня отсутствует»). В A7 запрещено менять общие движки, поэтому
ядро автономно (stdlib, без `app.*`); мотив — в docstring. Канонические инварианты
соблюдены дословно: next_open, полные бары, SL-first, запрет подстановки старого
prev_close, INCOMPLETE вместо «плоской позиции», непрерывность пути. Интеграция с
engine/Resampler — отдельная будущая задача, в A7 не выполнялась.
