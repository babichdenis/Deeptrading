## 1. Что делает модуль

`news_candidate_journal.py` (offline): читает явно заданный candidate JSONL и локальную
КОПИЮ архива A6; для каждого валидного базового кандидата считает A/B/C через принятый
`shadow_decide` и пишет `journal.jsonl`. `analyze_item`/API/collector/runtime не вызываются;
для C читаются только сохранённые анализы. Outcome/PnL в решение не подаются.

## 2. Закрытие 4 блоков REWORK r2

| Блок | Было (r1) | Стало (r2) |
|---|---|---|
| **1. Идентичность** | два id, различающиеся после 120 символов, обрезались A6 до одного `external_ref` → один `db_candidate_pk` | `external_ref = "a21:"+sha256(id+канонический payload)` (без обрезки) → разные допустимые id не коллизируют. id/ticker/версии — непустые строки (dict/list отклоняются), id≤200, ticker по шаблону `^[A-Za-z0-9._-]{1,20}$`. id+payload идемпотентен; конфликт id → reject |
