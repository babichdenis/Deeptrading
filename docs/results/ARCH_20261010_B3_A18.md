## Что реализовано

- Только функции обработки **закрытого минутного префикса**: накопление полных
  отдельных минут, полные 10min-бакеты A7 (`build_ticker_data`/`aggregate_10min`),
  ATR14 Wilder строго до решающего бара (`atr_before`), причинный диапазон/VWAP-proxy,
  `reset()`. Переиспользованы чистые хелперы A7; торговый `_walk` не копировался,
  третий движок не создавался.
- **C1 ORB**: OR = полные бары 10:00/10:10/10:20 (OR_high/OR_low); скан всех меток
  10:30–14:00 шагом 10 (включая 10:50); первое закрытие > OR_high → long, < OR_low →
  short (строгое неравенство); равенство → нет сигнала.
- **C2 VWAP-reversion**: VWAP-proxy typical-price volume-weighted с 10:00 по t;
  |dev| ≥ 1×ATR/VWAP; guard |VWAP_t − VWAP_{t−60min той же сессии}| < ATR; скан
  11:00–14:00. Сторона = −sign(dev).
- Выход `signal` | `skip` | `insufficient_context` с `candidate_id/ticker/day`,
  `observed_until`, `decision_close_time` UTC, `intended_entry_time` UTC, `side`,
  `atr`, значениями гейтов, `spec_hash`. В момент сигнала **нет** цены entry/SL/TP —
  только формулы (`open(intended_entry_time)`, `entry −/+ 2.0×atr`, `entry +/− 3.0×atr`).
- Один первый допустимый сигнал/день (`_done_days`); за пределами окон сигнала нет.
  Отсутствие entry-минуты обрабатывает последующее исполнение — здесь только намерение.

## Честные границы

- Только синтетика, вручную, без A10 и без рынка. Причинность проверена кейсами
  «будущий суффикс» и «дыра до решения».
- VWAP — 10min typical-price proxy, НЕ trade-level VWAP; единицы объёма (лоты/акции)
  неизвестны (A10); единый положительный множитель сокращается, переменная
  шкала/повреждённые веса — реальный риск (как в каноне A17).
- TP 3×ATR не равен «выходу ровно у VWAP»; экономический эффект не доказан.
- Market replay и подключение к runtime — только отдельным назначением.

(канон A17, `2a1ecab0…`). A7-хелперы не менялись; исправления только в своём модуле A18.

### Что исправлено по репро архитектора
1. **Валидация feed на границе до мутации состояния** (`_validate_bar`): aware ts →
   ValueError `feed_ts_naive`; выравнивание по минуте (second==microsecond==0) →
   `feed_ts_not_minute_aligned`; строгая монотонность/уникальность → `feed_ts_not_strictly_increasing`;
   конечные положительные OHLC и согласованные high/low → `feed_ohlc_invalid`;
   неотрицательный конечный volume → `feed_volume_invalid`. Невалидный бар не добавляется:
   **дубль не может стать десятой минутой бакета**; полнота = 10 различных минут.
2. **Контракт закрытой минуты**: `ts` — начало минуты; `observed_until = ts+1min UTC`
   (весь бар закрыт). Добавлено `last_bar_open_time`. В нормальном примере
   `observed_until == decision_close_time == 07:40Z`; сигнал не требует будущей минуты.
3. **Граница 14:10**: непробойный полный префикс до 14:09 (250 минут) → терминальный
   `no_breakout`/`no_signal` сразу на 14:10, без лишнего бара. Окна и spec hash не сдвинуты.
