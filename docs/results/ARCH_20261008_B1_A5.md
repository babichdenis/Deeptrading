**CLI (r2):**

```bash
# offline (default): чтение raw из --input, выходы в НОВЫЙ --out (никогда не перезаписываются)
~/.venvs/deeptrading/bin/python scripts/compare_candle_sources.py \
    --input <collected_artifact_dir> --out <new_out_dir>

# collect: ограниченный read-only сбор в свежий --out + сравнение
~/.venvs/deeptrading/bin/python scripts/compare_candle_sources.py --mode collect --out <fresh_dir>
```

Опции: `--mode {offline,collect}`, `--input` (каталог собранного артефакта, обязателен
в offline), `--out` (каталог выходов; в offline обязателен; в collect по умолчанию
свежий `<repo>/backend/reports/architect_20261008/b1/a5/<utc-stamp>`),
`--price-tolerance` (default 0.001, abs), `--facts` (путь к сохранённому A3 facts.json,
только collect).

**Exit codes:** `0` = загрузка OK; `2` = SOURCE_UNAVAILABLE/INCOMPLETE (и usage-ошибки
argparse); `3` = отсутствуют входные raw / `--out` содержит выходы (refuse) /
не заданы `--input`/`--out`.

**Границы collect (контракт, без изменений):** только SBER `BBG004730N88` / MOEX SBER
TQBR, 1min, окно `2026-09-08T12:30Z..13:10Z`; ISS — один день 08.09 с пагинацией,
максимум 10 страниц; БД не читается (третья сторона — сохранённый `db_probe.window`
из `031556Z/facts.json`); ошибки источников — только класс исключения + фиксированный
reason_code (без текста исключения); нулевые свечи не имитируются.

**Пайплайн (r2):** raw (раздельно, до нормализации) → нормализация времени в UTC
(ISS `begin` MSK→UTC через `parse_iss_begin`; T-Invest quotation units+nano→float;
DB decimal-строки→float; метка = НАЧАЛО минутного бара, сверка begin-to-begin) →
union timestamps → `validate_bar` на каждую запись (включая дубли) →
`analyze_entries` (неоднозначный источник исключается из сравнимых пар) →
`compare_sources` → `comparison.json` + `report.md` + `manifest.json`.

**Два статуса (r2):** `overall_status` (загрузка: все источники ok + load_complete)
и `comparison_quality_status` (данные: CLEAN / ISSUES по invalid/conflict/schema).
OK загрузки ≠ чистые данные; в report.md выводятся оба.
