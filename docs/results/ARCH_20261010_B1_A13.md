## 1. Ключевая семантика: A7 не оценивает выходные

A7 исключает бары main-сессии в выходные как DQ `session_bars_weekend`
(`day_strategies_core.py:396-399`), поэтому выходной день не попадает в `session_dates` и не
даёт ни сделки, ни skip. В eval-окне `2026-06-11..2026-10-08` (120 дней) у каждого тикера
ровно **34 присутствующих выходных** — они **исключены**, а не «потеряны стратегией».
Следовательно, «оцениваемые A7 даты» = присутствующие **weekday**-дни, и
`outcomes_total` каждой конфигурации сходится с ними (reconcile = **True** по всем 40
строкам ticker×config×scenario, 0 пересечений trade/skip).

## 5. SBER 2026-09-08T12:47Z — доказуемая цепочка

- Аномальная строка (`open=high=low=close=1.0`, `volume=0`) проходит `load_minute_csv`
  (цены положительны/конечны, OHLC не сломан, `volume>=0`) и **не помечается DQ** (в `dq.csv`
  SBER только `session_bars_weekend`).
- Её 10min-бакет = **15:40 MSK**; присутствуют лишь 3 минуты (12:41/12:46/12:47Z) → бакет
  **неполный**. По коду A7 ATR строится только по `full_session_bars` (`bar.is_full`,
  `day_strategies_core.py:404-419`), а бары решений берутся только из full bars → **неполный
  бакет исключён** из ATR/решений.
- На 2026-09-08 у всех конфигураций отсутствуют нужные полные бары → **входов нет**
  (`day_open_missing` для S1, бары решений 10:20/10:30 для S2); следовательно аномальная минута
  не попадает в path-scan исполнения.
- **Известно (по коду/данным)**: строка присутствует и не DQ; её бакет неполный и исключён;
  сделок SBER 2026-09-08 нет. **Только потенциально** (в A13 не пересчитывается): влияние через
  иные пути на конкретные последующие сделки. Срок «вымывания» Wilder ATR не утверждается;
  сделки не удаляются.

## 6. Три главных ограничения качества данных

1. **Календарь/выходные.** A7 исключает бары выходных (`session_bars_weekend`); 34 выходных дня
   на тикер не оцениваются, а не «теряются». Официальный календарь MOEX — NOT_VERIFIED.
2. **Неполнота источника.** Отсутствующие даты (GAZP/LKOH/VKCO 10-05..08, SFIN 10-06..08) и
   внутридневные пропуски дают skip-причины доступности (`day_open_missing`,
   `prev_close_missing`, `decision_bar_missing`), которые нельзя приравнивать к отсутствию
   сигнала (`no_gap`, `no_signal_*`).
3. **Неполные пути сделок.** У SFIN (88/136) и VKCO (24/179) высока доля INCOMPLETE — путь после
   входа обрывается; у SBER качество `KNOWN_BAD_INPUT` (аномалия §5), поэтому его итоги —
   диагностические, а не торговое преимущество.
