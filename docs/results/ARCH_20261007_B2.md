## Требование → реализация → проверка

| Требование (A2-C1) | Реализация | Проверка |
|---|---|---|
| Raw-проверка до агрегатора; optional missing/None = UNKNOWN, не подменять нулём; присутствующее нечисло → неполный результат | `raw_row_problem` до агрегации | параметризованные тесты raw; `invalid_raw:<field>` в coverage |
| Агрегат optional-поля null при unknown хотя бы у одного прогона; независимые метрики считаются | `aggregate_rows` | тесты unknown→null; известный net при DD=null |
| Переполнение агрегации не даёт неконечного результата | `overflow:<field>`, агрегат null | тест переполнения gw/net |
| trades/net_pnl обязательны независимо от rank; PF=None (gl=0), expectancy=None (trades=0) — случаи формул; min_profit_factor: PF=None при net>0 проходит | `metrics_complete`, формулы, `_af` | тесты формул; select_is → ELIGIBLE |
| Фильтр/rank требуют неизвестного поля → отказ с конкретной причиной | `incomplete_metrics:<field>` / `missing_rank:<field>` | тесты DD-фильтра и rank=None |
| rank валидируется на входе, в том числе при пустом наборе; неизвестный — понятная ошибка | `rank_by not in RANK_FIELDS` → RankFieldError | тест неизвестного rank на пустом входе |
| Точное покрытие label×ticker×exit; повреждённое не теряется молча; неизвестные label/без идентичности — в диагностике фазы | `coverage_reasons` + `unknown_labels`/`unattributed` | тесты покрытия |
| IS: неполный кандидат не допускается, причины сохранены, остальные обрабатываются; все отказаны → []/NO_ELIGIBLE_CANDIDATES без fallback | `eligible_labels`/`select_is` | тесты IS |
| OOS: только допущенные; невалидное окно — статус/причина/metrics=null согласованно во всех представлениях | `oos_rows`/`build_oos_matrix` | тесты OOS |
| Суммы/медианы/списки только из OK; все OOS невалидны → итог не изображает безубыточность | сводка из status==OK | тест «все невалидны» |
| Robustness: те же проверки; нет валидного OOS — пропуск; post_selection | robustness-блок run_wf | тесты robustness/пропуска |
| Строгий JSON без NaN/Infinity во всех разделах; unknown → null с контекстом; ошибки sanitized | `allow_nan=False`; `sanitize_text` | тест строгого парсера |
