## 4. Ветки теневого решения (без изменений с r5)

- **A** (`a6-shadow-1`): новости не учитываются → `would_allow/branch_a_no_news_veto`.
- **B** (`a6-kw-1`): bound-риск `would_veto/keyword_risk_event` (приоритет) →
  `source_unavailable`/`insufficient_coverage` → unbound `unknown/risk_unbound_ticker` →
  `would_allow/no_risk_keyword`. Покрытие B в r6 НЕ открывалось.
- **C** (r5): confirmed veto (приоритет) → `source_unavailable`/`insufficient_coverage` →
  `risk_unbound_ticker` → `incomplete_analysis_coverage` (явный тикер кандидата без анализа)
  → `relevance_unestablished` (неустановленная релевантность) →
  `no_confirmed_evidence` → `would_allow/no_risk_event` (только доказанно нерелевантные).
- `decision_time` строго = сохранённый у кандидата; несовпадение → `DECISION_TIME_MISMATCH`.

`OBSERVER_TICKERS = (SBER, GAZP, LKOH, VKCO, SFIN)` — минимальный детерминированный
список распознаваемых чужих тикеров (текущий наблюдаемый scope, A8). Новых моделей,
источников и режимов r6 не добавлял.
