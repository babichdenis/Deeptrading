## 3. Качество данных vs гипотеза

`data_status` по combo×scenario: **complete_observed 24 строки** (12 combo), **incomplete_data 40** (20 combo), **known_bad_input 16** (8 combo, SBER). Полный результат при INCOMPLETE — UNKNOWN (120 путей `path_gap_after_entry`, A19); known-bad SBER исключён из выводов о пригодности. Таким образом, часть «отрицательности» — вопрос качества данных/издержек, а не доказательство отсутствия ценового преимущества; различить их без незагрязнённого наблюдения нельзя.

## 5. Вывод

Прежде всего: между сценариями издержек сделки не «пропадают» — 11 комбинаций пересекают нуль, значит **запас на издержки у многих ячеек минимален**; у 9 он отрицателен уже при 5/2 по net при положительном gross. `complete_observed`-ячейки (24 строки) пригодны для описательного чтения; `incomplete_data`/`known_bad_input` — нет (UNKNOWN, не выводить «пригодно/непригодно»). Это диагностика чувствительности к издержкам, **не** доказательство прибыльности и **не** OOS/holdout; реальные тарифы/спреды не назначаются, линейная экстраполяция break-even не делается.
