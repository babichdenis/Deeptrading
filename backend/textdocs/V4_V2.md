## Выводы
1. **V2 стабильно лучше дефолта** на обоих месяцах (+20% июль, +46% август) на канонических 5 акциях.
2. Комиссии и проскальзывание **учитываются честно**: commission_rate=0.0005, slippage_bps=2.0.
   - Август V2: gross 18,114₽ − costs 8,060₽ (commission 5,757₽ + slippage 2,303₽) = net 12,358₽.
3. Размер позиции: по реальному лоту из БД (RUAL/SNGSP/AFLT/NLMK lot=10, MVID lot=1), capital=10_000.
4. **Ранее выявленный баг**: `compute_ensemble` считает qty по `candles[0].open` (первая свеча поданного окна). Решение — подавать движку ТОЛЬКО свечи торгового дня (как бот в live), без 30-дневной истории прогрева.

## Анализ убыточных сделок V2 (июль+август, 1185 сделок, 283 убытка = 23.9%)
1. **По причине выхода**: signal_exit 186 убытков (-2,535₽, MFE 1.11R), stop_loss 96 (-3,798₽, MAE 1.33R). Только 1 сделка из 186 дошла до цели (MFE≥2R) — «держать дольше» почти ничего не дало (подтверждено экспериментом opposite_hold).
2. **Ложный вход** (MAE≥1R, MFE<1R): всего 5 сделок (-162₽). **Ложный разворот** (MFE≥1.5R): 48 сделок (-486₽). **Середина** (MFE 0.5-1.5R): 133 сделки (-1,887₽) — главный источник убытка.
3. **По часу**: входы 07-08 UTC (утро) и 13-14 UTC (вечер) дают больше убытков (24-28% vs 15-23% днём).
4. **По направлению**: SHORT хуже (27% убыток vs LONG 21%).
5. **Комиссии**: 115 из 283 убытков (41%) — убыток ≤ комиссии (gross≥0). Средняя стоимость сделки 14₽.
6. **Прибыль делают target** (722 сделки, +31,191₽ = 80% всех выигрышей).

## Направление тюнинга (итог)
- Выход по сигналу — правильный, НЕ менять.
- Тюнить ВХОД: меньше ложных входов (особенно SHORT утром/вечером).
- Не тюнить выход/держание.
